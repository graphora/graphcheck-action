# Security Policy

## Supported versions

Security fixes are applied to the latest `v1` release and the `main` branch.

| Version | Supported |
| --- | --- |
| Latest `1.x` | Yes |
| Earlier releases | No |

## Reporting a vulnerability

Do not open a public issue. Use
[GitHub private vulnerability reporting](https://github.com/graphora/graphcheck-action/security/advisories/new)
to share the affected version, reproduction steps, impact, and any suggested mitigation.

If private reporting is unavailable, contact `support@graphora.io` with the subject
`GraphCheck Action security report`. Do not include secrets or production graph data.

We will acknowledge a report within three business days and coordinate disclosure after a fix is
available.
